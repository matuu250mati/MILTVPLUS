Ayuda técnica

Soporte y diagnóstico

Consultá estas comprobaciones antes de reinstalar la aplicación.

La descarga no empieza

Comprobá la conexión, probá el enlace de Releases y verificá que el televisor tenga espacio disponible.

Android bloquea el APK

Revisá el permiso de instalación para Downloader. Continuá únicamente si confiás en el origen del archivo.

No se instala la actualización

Una firma distinta, una versión incompatible o un paquete diferente pueden impedir la instalación sobre la app existente.

Preguntas frecuentes

Respuestas rápidas.

¿La página aloja el APK directamente?

No. El botón descarga el archivo publicado en GitHub Releases; esta página funciona como portal informativo y punto de acceso.

¿Puedo instalar una actualización sin desinstalar?

Normalmente sí, si conserva el mismo identificador de paquete, usa una firma compatible y tiene un número de versión superior. Android siempre puede requerir confirmación del usuario.

¿La actualización se instala sola?

No. La aplicación puede avisar y descargar una versión nueva, pero Android exige intervención/confirmación para instalar APK externos. No se debe prometer instalación silenciosa en un dispositivo normal.

¿Por qué no reproduce un canal o una película?

La disponibilidad depende de que la URL sea accesible y de que el formato, los permisos y el servidor sean compatibles. Un título visible en el catálogo no garantiza que su fuente siga activa.

¿Qué hago si el control remoto se queda en un campo?

Probá flechas arriba/abajo y OK. Si el foco no avanza, registrá el modelo del televisor, la versión de Android TV y el paso exacto para reportarlo en GitHub.

¿Dónde veo los cambios y las versiones?

Las Releases publicadas y el historial de código están disponibles en el repositorio oficial del proyecto.
