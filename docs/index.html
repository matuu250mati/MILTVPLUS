Cómo instalar

  1. En Downloader, abrí el navegador o el campo de URL.
  2. Visitá esta página y seleccioná DESCARGAR MILTVPLUS APK.
  3. Cuando termine la descarga, abrí el archivo APK.
  4. Si Android lo solicita, permití a Downloader instalar aplicaciones desde esa fuente y volvé al instalador.
  5. Confirmá la instalación y abrí MILTVPLUS.

Nota: los nombres de los menús pueden variar según el modelo de televisor y la versión de Android/Google TV.

Preguntas frecuentes

¿Cómo instalo el APK?

Descargalo desde el botón de esta página, abrí el archivo y seguí las indicaciones del sistema. Habilitá la instalación desde Downloader solo si confías en el archivo y en su procedencia.

¿Cómo navego con el control remoto?

Usá las flechas para moverte entre los elementos, el botón central/OK para seleccionar y Atrás para regresar. La respuesta puede variar según el control y el dispositivo.

¿Cómo actualizo MILTVPLUS?

Volvé a esta página y descargá la versión publicada más reciente. Si Android no permite instalarla sobre la versión existente, no desinstales la aplicación de inmediato: podría eliminar datos locales. Revisá primero el mensaje de error y la compatibilidad de firma.

¿Por qué Android muestra una advertencia?

Android suele advertir cuando se instala una aplicación descargada fuera de una tienda. Continuá solo si reconocés el origen y querés instalar el APK.

¿Esta página me da un código de 5 dígitos para Downloader?

No. Los códigos numéricos cortos los genera el servicio de AFTVnews Downloader. Este sitio no puede asignar ni inventar uno. Podés abrir esta página desde el navegador de Downloader o registrar esta URL en el servicio de códigos de AFTVnews si está disponible para tu cuenta.
